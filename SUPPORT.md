# Support

Use GitHub Issues for reproducible bugs, feature proposals and research questions. Choose the matching form and include version/commit, environment, exact command, redacted logs, expected behavior and observed behavior. Do not include secrets, personal data or private tender documents.

For usage questions, first read [README.md](README.md), [docs/operations.md](docs/operations.md), and the integration contract. External-service outages should include the dependency/status response; BidWeave must report unavailable integrations explicitly rather than implying success.

Security vulnerabilities are private reports only; see [SECURITY.md](SECURITY.md). This project offers no SLA, legal advice, eligibility guarantee, award guarantee or guaranteed response time.
