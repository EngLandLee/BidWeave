# BidWeave

Headless, evidence-aware tender-response operations for OLP Open Source 2026.

BidWeave connects requirements, evidence, ownership and approvals to the exact tender revision. An amendment reopens the affected work rather than silently reusing a stale approval.

Development is tracked in [GitHub Issues](https://github.com/EngLandLee/BidWeave/issues) and changes are integrated through feature pull requests. The acceptance contract is in [PRODUCT.md](PRODUCT.md).

Own source is Apache-2.0. Third-party software and public datasets retain their respective licenses. Synthetic examples do not establish real company credentials or legal compliance.
